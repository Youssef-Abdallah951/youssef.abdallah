# 💻 Youssef Abdallah — Personal Portfolio

A modern, responsive, and professional personal portfolio website showcasing my skills, projects, certificates, and experience as a Frontend Developer.

The portfolio is designed with a clean and modern UI, smooth animations, responsive layouts, Dark/Light Mode, and a customizable multi-color theme system.

---

## ✨ Features

- 🏠 Modern Hero Section
- 👨‍💻 About Me Section
- 🛠️ Skills & Technologies
- 📂 Projects Showcase
- 🎓 Certificates Section
- 📧 Contact Section
- 🌙 Dark / Light Mode
- 🎨 Multi-Color Theme System
- ⚙️ Custom Settings Panel
- 💾 Theme Preferences saved with LocalStorage
- 📱 Fully Responsive Design
- ✨ Smooth Animations & Hover Effects
- 🔗 Social Media Links
- 📩 Contact Form
- ⚡ Fast and Lightweight

---

## 🎨 Multi-Color Theme

The portfolio includes a customizable theme system with multiple accent colors:

-  Sky Blue
-  Green
-  Purple
-  Pink
-  Orange

Users can change the website's primary accent color from the Settings panel.

The selected theme is automatically saved using `localStorage`.

---

## Appearance

The website supports:

- ☀️ Light Mode
- 🌙 Dark Mode

The selected appearance is also saved and restored automatically when the website is reopened.
